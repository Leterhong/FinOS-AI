核心模块

12 个业务模块覆盖企业金融研判全流程。

📊

经营决策台

统一观察项目、资料、风险、任务和 Agent 运行态。Priority Work 面板展示需要人工处理的事项。

📁

项目中心

管理企业研判项目、行业、融资需求、负责人。支持 Table/Board 双视图。

📄

资料研判

上传 PDF、Word、Excel、CSV、图片。四阶段管线：解析 → 抽取 → 规则判定 → 叙述。事实逐条携带原文引用。

🛡️

风险中心

按严重度聚合风险信号。结构化详情抽屉展示 What/Why/Evidence/Rule/Impact/Review/Traceability。

⚖️

规则库

管理准入、授信、并购规则。结构化条件 + Visual View 决策链 + 测试样本记录 + 版本回放。

🤖

Agent 中心

编排资料理解、规则匹配、风险研判 Agent。每条运行可展开执行轨迹。

💬

智能研判助手

基于项目上下文的 AI 流式对话。只使用工作区明确数据，区分事实与推断。

🔗

AI 模型中心

接入 OpenAI、DeepSeek、通义千问、Ollama 等。密钥服务端 AES-256-GCM 加密保存。

🏛️

企业治理

五级 RBAC、项目授权、数据密级、人工复核队列、规则版本回放、模型评测、审计。

技术架构

Next.js 15 + FastAPI + PostgreSQL/SQLite + Redis（可选）

Browser └─ Next.js 15 / React 19 / TypeScript strict / Tailwind CSS ├─ 企业零数据工作区（Zustand 本地持久化 + 服务端同步） ├─ Route Handlers（工作区会话、模型配置、AI 网关 SSE） ├─ AES-256-GCM 模型凭据存储（仅服务端可解密） └─ FastAPI ├─ 访客会话 / JWT / HttpOnly Refresh Cookie（原子轮换） ├─ 企业持久化 / 组织治理 / 确定性规则引擎 ├─ SQLite（开发）/ PostgreSQL 16（生产） └─ Redis（可选，限流 + 缓存 + 吊销共享）

快速开始

5 分钟完成一次从"上传资料"到"输出风险清单"的完整研判。

1

接入 AI 模型

到模型中心添加你自己的大模型（支持 DeepSeek、OpenAI、Ollama 等），测试连接后保存。

2

创建企业项目

新建一个融资、尽调或经营分析项目。项目是所有资料、风险和 AI 分析的容器。

3

上传资料

上传 PDF、Word、Excel 或图片。系统自动抽取结构化事实（逐条携带原文引用）。

4

查看研判结果

查看规则命中（确定性引擎判定）和 AI 分析叙述。点击事实可定位到原文。

5

人工复核

核验候选风险、登记缓释措施。所有操作留痕进入不可篡改审计记录。

6

导出报告

复制风险清单或项目研判报告为 Markdown 格式，用于授信或尽调流程。

设计原则

这些原则决定了 FinOS AI 与普通 AI Chat 产品的本质区别。

✓

Evidence First

重要判断必须能回到原始资料、事实字段和引用位置。UI 提供 Evidence Chain 逐级追溯。

✓

Human in the Loop

AI 生成草稿和线索，关键决策由授权人员确认。系统不执行审批、授信或付款。

✓

Explainable Rules

规则命中由确定性引擎计算（非 LLM），展示命中原因、潜在影响和证据。

✓

Secure by Default

密钥不进入前端，上传和出站访问经过安全边界，生产弱密钥拒绝启动。

✓

Zero Preset Data

不预置任何企业、金额、风险或 AI 结论。所有数据由用户主动录入。

✓

Open & Self-hosted

MIT 开源，支持自托管，按业务需要扩展。

GitHub 使用指引 贡献指南 安全策略 更新日志
