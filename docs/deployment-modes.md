# FinOS AI 部署模式与企业上线边界

FinOS AI 的默认开源体验目标是：让评估者无需登录即可验证“企业项目 → 自带模型 → 资料事实 → 规则匹配 → 候选风险 → 人工复核 → 报告导出”的产品闭环。它不是匿名公开的生产 SaaS。

## 单机体验模式

- 适用：本机试用、产品评估、开发验证、非敏感测试资料。
- 身份：随机浏览器工作区会话，不是企业账号或组织身份。
- 业务状态：默认以前端工作区为主；启用 FastAPI 后可同步企业对象。
- 模型：BYOM；密钥仅提交给本机服务端并加密保存，浏览器只接收掩码。
- 禁止场景：公共匿名站点、共享浏览器、真实客户机密、需要多人审批或法定留存的业务。

## 企业生产模式

生产部署者必须在现有代码基线之上完成：

1. 对接企业身份源和 SSO，建立组织、成员、停用及会话撤销流程。
2. 为项目、资料、规则、风险、任务、报告和模型配置建立 RBAC/ABAC 权限。
3. 使用 PostgreSQL 和受控对象存储，制定加密、备份、恢复、删除与留存策略。
4. 把关键写操作同步到追加式审计系统，并限制审计日志修改与删除权限。
5. 评估模型供应商的数据使用、地域、保留和训练政策；按数据等级决定是否允许外发。
6. 配置 HTTPS、独立强密钥、密钥轮换、出站网络策略、漏洞管理、监控和安全告警。
7. 根据业务所在地区和金融业务类型完成隐私、网络安全、模型治理及人工审批评估。

## 能力声明原则

界面、文档和对外宣传只能描述当前已实现并验证的能力。以下表述在没有对应控制与证据前不得使用：

- “已通过监管合规”或“自动保证合规”；
- “完整多租户”“银行级权限”或“不可篡改审计”；
- “AI 自动审批”“自动授信”或可以绕过人工复核的高影响决策；
- “数据绝不离开本地”（BYOM 请求会发送给用户配置的模型服务）。
