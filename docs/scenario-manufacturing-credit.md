# 行业剧本 · 制造业流动资金贷款尽调

> 本剧本演示 FinOS AI 如何完成一次制造业授信尽调：从资料到可核验的风险清单与研判报告。所有步骤在产品内可复现；文中涉及的企业与数据为示例。

## 场景

- **企业**：某精密零部件制造企业（示例）
- **任务**：流动资金贷款尽调（授信 5,000 万元）
- **角色**：客户经理、风控复核人
- **关注点**：经营现金流、客户集中度、应收账款周转、担保方式、财务承诺

## 步骤与产物

| 步骤 | 操作位置 | 产物 |
| --- | --- | --- |
| 1. 建项目 | 项目中心 → 新建 | 企业研判项目（含行业=制造业） |
| 2. 上传资料 | 资料研判 → 批量上传 | 审计报告、借款合同、产销存/流水 |
| 3. AI 研判 | 自动四阶段管线 | 结构化事实（逐条带引用）、规则命中、分析叙述 |
| 4. 规则匹配 | 规则库（制造业分组） | 经营现金流/客户集中度/应收周转等命中 |
| 5. 风险生成 | 风险中心 | 候选风险（含证据、规则、影响、状态） |
| 6. 人工复核 | 风险中心 → 逐条核验 | 已确认/已缓释风险 |
| 7. 流程推进 | 流程中心 | 补充资料→复核→交付任务闭环 |
| 8. 交付 | 项目详情 → 导出 | Markdown 研判报告（含引用与状态） |

## 本场景用到的规则（制造业模板）

- 经营活动现金流量净额低于 0（经营造血为负）
- 客户集中度高于 60%（前五大客户收入占比）
- 应收账款周转率低于 3
- 资产负债率高于 65%
- 经营现金流/流动负债低于 25%
- 担保方式偏弱（人工登记）

## 典型风险（示例）

| 风险 | 等级 | 依据 |
| --- | --- | --- |
| 经营现金流为负，收入增长与回款背离 | 重大 | 现金流净额 -860 万元；营收 +11.3% |
| 客户集中度偏高 | 高 | 前五大客户占比 61.2% |
| 应收账款周转放缓，账期超 90 天 | 高 | 平均回款账期 92 天 |
| 担保方式偏弱，仅实控人保证 | 中 | 拟签合同担保条款 |

## 复核与留痕

- 每条候选风险须由复核人核验后方确认；核验意见与缓释措施写入审计记录。
- 项目活动摘要汇总创建、解析、核验、任务推进事件。
- 导出的研究报告包含事实引用、财务指标、风险状态与人工流程。

## 与外部数据的结合

- **汇率 / LPR**：项目详情「外部数据联动」折算外币金额、查看利率走势。
- **上市公司公告（巨潮资讯）**：按企业名检索公告，关注诉讼仲裁、股权质押、业绩预告等。
