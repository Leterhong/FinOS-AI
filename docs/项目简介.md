# FinOS AI 项目简介

FinOS AI 是一个完全开源、可自托管的个人财富操作系统（Personal Wealth OS），采用 MIT 协议，不设置任何付费墙。

它既不是记账软件、也不荐股，而是把你的真实资产、负债、收支与目标，汇聚成一个可对话、可推演、可主动提醒的「财富数字分身」。你可以用自然语言向它提问、让它模拟未来情景、由它主动发现问题并提醒你。

产品坚持三条设计底线：数据是你的——全部自托管，字段级 AES-256-GCM 加密，严格用户隔离；模型是你的——自带模型（BYOM），在应用内填自己的 API Key，项目不代理任何模型服务；没有付费墙——无订阅、无会员、无交易撮合。

核心能力包括财富数字分身建模、六维财富评分、情景模拟推演、AI 助手（支持多模态识别录入）、五大专项 AI CFO 智能体，以及事件驱动加定时的智能自动化。财富时间线串联过去、现在与未来，让每一笔决策都有据可循。

技术栈为 Next.js 15 前端加 FastAPI 后端，包含 60 个前端路由、44 张数据表与 112 项自动化测试，支持 Docker 一键部署，测试可不依赖任何大模型完整运行。

你的财富，你做主。
