# FinOS AI · 一页纸简介

## 一句话

面向企业经营与风险研判的开源 Agent 工作台：把企业资料、经营事实、业务规则与外部研究组织成一条**可追溯、可复核**的研判链路。

## 目标用户

信贷经理、风控与合规人员、尽调分析师、投研人员。

## 解决的问题

- 资料散落：PDF / Word / Excel / 图片，人工整理慢、容易漏。
- 结论不可追溯：说不清依据哪份资料、哪条规则、哪个位置。
- 生成式幻觉：直接让模型给结论，不可信、不可审计。
- 协作与治理缺失：多角色、密级、复核、审计无从落地。

## 核心差异

1. **确定性规则引擎 + 大模型分工**：命中判定由纯函数完成，模型只负责资料理解与叙述生成，结论可复现。
2. **证据优先**：每条事实携带原文引用与行号 / 单元格 / 图像坐标，可逐级追溯到原始资料。
3. **人机复核闭环**：候选风险必须经人工核验才成为正式风险，每一步操作留痕。
4. **企业治理内建**：组织角色、项目授权、数据密级、复核队列、模型评测、审计开箱可用。
5. **自带模型、可自托管**：密钥在服务端以 AES-256-GCM 加密，支持自建模型与私有化部署。
6. **外部数据可接入**：内置汇率（ECB）、LPR、世界银行、GLEIF、SEC EDGAR 与巨潮资讯上市公司公告等免费公开数据源，无需密钥，结果一律标注需人工复核。

## 可信证据（可复现）

- **确定性引擎评测**：71 条规则模板、296 条基准用例、100% 通过，`npm run benchmark` 一键复现（见 `docs/benchmark.md`）。
- **质量门禁**：TypeScript 严格模式、ESLint、前端契约测试、规则引擎单元测试、后端 pytest、Next.js 生产构建全部通过，并由 CI + CodeQL 自动执行。
- **安全基线**：短期 Access Token + HttpOnly Refresh Cookie、AES-256-GCM 字段加密、SSRF 防护、分级限流、可信代理、页面 CSP（报告模式）。
- **文档齐全**：35 张界面截图的图文详解、完整使用文档、部署指南与安全设计。

## 体验路径（约 3 分钟）

1. 打开首页 → 经营决策台总览。
2. 项目中心 → 进入企业项目工作台。
3. 资料研判 → 查看结构化事实、规则命中与证据定位。
4. 风险中心 → 打开风险详情（What / Evidence / Rule / Impact / Review / Traceability）。
5. 规则库 → 浏览 71 条模板，并查看「确定性引擎自检」面板。
6. 企业治理 → 权限、复核、模型评测、连接器与审计。
7. 数据大屏 → 经营与风险全景。

## 部署与许可

- 本地：Node.js 20+ / Python 3.11+，命令见 `docs/user-guide.md`。
- 生产：Docker Compose 一键部署（`bash deploy.sh`），PostgreSQL 16 + Redis 7。
- 许可：MIT，支持自托管与按业务扩展。

> FinOS AI 提供信息分析与决策辅助，不构成投资、授信、法律、审计或合规意见。
