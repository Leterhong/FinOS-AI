## 如何交叉核验

1. 在平台对话记录中定位与上表功能对应的需求/实现/修复片段。
2. 用 `git show <提交>` 查看该次改动的真实代码差异。
3. 用 `npm run test:unit`、`npm run benchmark`、`npm run ai-eval`、`node tests/e2e/main-chain.mjs` 复现质量与效果证据。
