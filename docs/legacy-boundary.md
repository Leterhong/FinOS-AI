# 旧版个人财富模块边界

FinOS AI 当前唯一产品方向是“面向企业经营与风险研判的金融服务 Agent”。前端主路径、企业状态、AI 上下文和服务端持久化不得依赖个人资产、持仓、预算或财富数字孪生。

2026-08-31 已移除最后一批未被引用的 `src/wealth` 与 `src/twin` 源码。后端仍保留部分早期数据库表和迁移，是为了保证已部署实例能够沿同一 Alembic 链升级；这些表不进入当前 UI、企业 AI 上下文或新功能开发。

后续处理原则：

- 不在企业页面重新引入个人账户、持仓、交易或预算模型。
- 旧数据库迁移只做兼容和安全修复，不扩展个人财富能力。
- 若未来完全移除旧表，必须单独发布迁移、备份与回滚说明，不能直接破坏现有部署数据。
- 新功能必须能落在资料理解、规则匹配、风险提示、投研整理或人工流程辅助之一。
