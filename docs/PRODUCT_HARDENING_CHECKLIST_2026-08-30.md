# FinOS AI 核心强化验收清单（2026-08-30）

本清单只覆盖“面向企业经营与风险研判的金融服务 Agent”目标。股票交易、个人记账、支付订阅、社交社区和无证据的多 Agent 展示不进入本轮范围。

## P0 合规真实性

- [x] 隐私说明不再描述个人财富数字孪生、注册/注销等旧产品能力。
- [x] 服务条款明确企业研判、BYOM、人工复核和部署者责任边界。
- [x] 首次使用顺序与真实依赖一致：项目 → 模型 → 资料 → 规则 → 研判。
- [x] 旧版无项目归属的运行记录不得影响当前项目判断。

## P0 证据与风险

- [x] 保存结构化事实，而不是只保存事实数量。
- [x] 每条事实包含文件、原文、位置、单位、报告期和复核状态。
- [x] AI 产出登记为“候选风险”，不能直接冒充正式风险。
- [x] 风险确认必须记录确认人、意见和时间。
- [x] 风险引用事实、规则版本和 Agent 运行 ID。

## P1 项目闭环

- [x] 建立 `/cases/[id]` 项目详情工作台。
- [x] 集中展示资料、事实、风险、规则、任务、底稿和 Agent 运行。
- [x] 支持项目编辑、状态更新和归档；当前不暴露不可恢复的项目删除入口。
- [x] 项目完整度显示完成项和缺失项，不只显示不透明百分比。
- [x] 项目时间线记录关键动作。

## P1 规则与人工流程

- [x] 规则验证基于测试样本和实际结果，不使用“一键标记已测试”。
- [x] 保存规则版本、测试人、测试时间和测试结果。
- [x] 任务支持说明、重新指派、退回、完成意见和操作历史。
- [x] 风险核验与任务推进均保留操作证据。

## P1 财务结构化与交付

- [x] 从结构化事实识别财务科目、报告期和单位。
- [x] 计算可解释的偿债、盈利、营运和现金流指标。
- [x] 展示同比/跨期变化和数据缺口，不编造缺失科目。
- [x] 生成项目研判报告，包含事实、规则、风险、复核和免责声明。
- [x] 支持 Markdown 导出，所有关键结论保留引用。

## P2 工程化与企业部署

- [x] 文件支持批量选择、逐项进度和失败重试。
- [x] 明确 OCR、扫描件和大文件处理边界。
- [x] 模型中心展示任务角色、失败诊断和调用治理信息。
- [x] 区分单机体验模式与企业部署模式。
- [x] 企业模式规划组织、角色、项目权限、留存和不可抵赖审计。
- [x] 清理或隔离个人财富旧模块，减少维护与安全面。

## 完成门槛

- TypeScript、ESLint、前端契约、规则引擎、Python 后端/AI 测试全部通过。
- Alembic 迁移链唯一且可升级。
- Next.js 生产构建通过。
- 至少使用两个企业项目完成浏览器交叉回归，确认资料、事实、风险、任务、底稿和对话不串项目。
- 空工作区、无模型、模型失败、无资料、无规则和旧版数据均有明确可恢复路径。
